# IEEE-PAPER-SPEC — IEEE Formatting Specification

Formatting rules derived from the provided IEEE conference template
(`rubrics/FinalReport_Template_IEEE FORMAT.docx`) and the evaluation rubric.

## 1. Document Format
- IEEE two-column conference format, US Letter.
- Title (paper title style), author line(s), affiliations.
- Abstract (italic run-in head), Index Terms / Keywords.

## 2. Headings
- Section heads: uppercase Roman numerals (I, II, III…).
- Use Heading 1–4 hierarchy; subheads only if ≥2 subtopics.
- Component heads (Acknowledgment, References) use Heading 5.

## 3. Sections (order)
Abstract → Introduction → Related Work → Methods → Experimental Setup → Results →
Discussion → Limitations → Conclusion → Acknowledgment (optional) → References.
Content per [REPORT-SPEC.md](REPORT-SPEC.md).

## 4. Figures & Tables
- Figures: caption **below**, "Fig. 1" abbreviation, 8 pt labels, words not symbols on axes,
  units in parentheses.
- Tables: title **above**, Roman-numeral numbering.
- Place after first citation; large items may span both columns.

## 5. Equations
- Numbered consecutively, flush right in parentheses `(1)`.
- Define all symbols near the equation.

## 6. References
- Numbered in brackets `[1]`, consecutive by appearance.
- Punctuation follows the bracket. IEEE reference style.
- Give all author names unless ≥6 authors.

## 7. Units & Style
- SI units; zero before decimals (`0.25`); "data" is plural.
- Remove all template guidance text before finalizing.

## 8. Deliverable
- `report/paper.pdf` (final) + editable source.
- Figures from `artifacts/figures/`, tables from `artifacts/tables/`.
- Team contribution statement included (rubric Writing requirement).
